# CLF Training Studio — branch scaffold

The new feature branch contains setup metadata and dependencies only. The full functional Studio source ZIP was delivered separately in the accompanying ChatGPT conversation. **Do not treat this GitHub branch ZIP as a runnable Studio yet:** `clf_studio/core.py` and `clf_studio/app.py` were not successfully uploaded by the repository connector. To finish installation, extract the delivered standalone source ZIP and copy its `clf_studio/`, `sample_data/` and `tests/` folders into a checkout of this branch, then commit and push those files normally. The existing `master` branch and original TensorFlow `pipeline.py` are unchanged.

Once these files are present: `python -m pip install -r clf_studio/requirements.txt`, then `python -m streamlit run clf_studio/app.py`. Train on Data Collector processed JSONL with verified metric coordinates. The Studio provides a standalone experimental PyTorch Wi-Fi/BLE overlapping-cell model, not the original TensorFlow Multi-CEL training pipeline. Real-time step/PDR fusion, mobile scanning and Android APK are not included.
